# ⚡ Yandex Disk Multi-Downloader

Userscript для автоматического скачивания всех файлов из открытой папки Яндекс.Диска одним кликом. Обходит ленивую загрузку, не теряет дубликаты, не скачивает «не тот» файл.

**Версия:** 1.0.0 · **Лицензия:** MIT

---

## Установка

1. Установите менеджер userscript: [Tampermonkey](https://www.tampermonkey.net/) / [Violentmonkey](https://violentmonkey.github.io/) / [Greasemonkey](https://www.greasespot.net/).
2. Создайте новый скрипт и вставьте код `yandex-disk-multi-downloader.user.js`.
3. Сохраните (Ctrl+S).

## Использование

1. Откройте папку на `disk.yandex.ru/d/...` или `/client/...`.
2. Нажмите жёлтую кнопку **«⚡ Скачать все файлы»** в правом нижнем углу.
3. Подтвердите запуск.
4. **Разрешите браузеру множественные загрузки**, если появится запрос.
5. Дождитесь итогового окна — файлы в папке «Загрузки».

**Остановка:** повторный клик по кнопке (станет серой «⏳ Остановка...»).

## Возможности

- Обход ленивой загрузки (авто-скролл до конца папки).
- Защита от дубликатов — ключ `имя + размер + дата + длительность`.
- Защита от скачивания не того файла — проверка имени в action bar перед кликом.
- Корректная остановка и очистка таймеров.
- Авто-остановка при SPA-навигации (смена URL).
- Логи в консоли (F12) + итоговая статистика.

## Настройки (`CONFIG` в начале скрипта)

| Параметр | По умолчанию | Когда менять |
|---|---|---|
| `DELAY_BETWEEN_FILES` | 700 мс | Увеличить, если браузер «давится» загрузками |
| `DELAY_AFTER_SCROLL` | 1000 мс | Увеличить на медленном соединении |
| `MAX_WAIT_FOR_BUTTON` | 2500 мс | Увеличить, если кнопка не успевает появиться |
| `MAX_WAIT_FOR_NAME` | 1200 мс | Увеличить при пропусках «не подтверждён в action bar» |
| `SCROLL_STEP` | 700 px | Уменьшить на медленном соединении |
| `MAX_EMPTY_SCROLLS` | 10 | Увеличить для очень больших папок |

## Решение проблем

**Кнопка не появляется** → проверьте, что скрипт активен; обновите страницу; в консоли должно быть `[Yandex Disk Downloader] v1.0.0 запущен`.

**Браузер блокирует скачивания** → настройки сайта → «Автоматические загрузки» → «Разрешить».

**Файлы пропускаются** → в консоли указана причина; увеличьте `MAX_WAIT_FOR_NAME` и `MAX_WAIT_FOR_BUTTON`.

**Скрипт зависает** → в консоли `10 пустых скроллов подряд` — пагинация Яндекса не отвечает; обновите страницу.

**Скачался не тот файл** → в v1.0.0 заблокировано проверкой имени. Если всё же произошло — пришлите лог в [Issues](https://github.com/DeivBoo/yandex-disk-multi-downloader/issues).

**«Страница была изменена. Скачивание остановлено.»** → сработала защита от SPA-навигации; перезапустите скрипт в новой папке.

## Ограничения

- Только файлы в текущей папке — **без рекурсии** по подпапкам.
- Каждый файл скачивается отдельно (не ZIP-архивом).
- Зависит от вёрстки Яндекса — после редизайна селекторы могут потребовать обновления.
- Не обходит капчу / антибот.
